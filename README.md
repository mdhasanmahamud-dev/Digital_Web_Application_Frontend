# Digital Management Web Application

A full-stack web application for managing **users, teams, projects, and contacts** from a centralized dashboard.

The application is built with **React, Vite, Tailwind CSS, React Router, TanStack React Query, Axios, React Hook Form, Recharts**, and a **Node.js + Express + MongoDB backend**.

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
